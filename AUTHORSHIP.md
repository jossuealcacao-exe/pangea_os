# Declaración de autoría

Pangea OS fue concebido y dirigido por **Jossue Alcalá** como un sistema operativo universal para creación, mantenimiento y comercialización de sitios web mediante múltiples agentes de IA.

## Aportación humana declarada

- Filosofía “Uno para gobernarlos a todos”.
- Arquitectura multiagente y multiplataforma.
- Integración de portafolios y proyectos existentes como conocimiento operativo aislado.
- Requisitos de contexto, backlog, bugs, UX/UI, front, backend y QA.
- Separación entre Pangea OS y AHP+.
- Uso de `/agent` como interfaz de memoria Git-backed.
- Dirección, selección, organización y aceptación del sistema.

Las herramientas de IA se utilizaron como instrumentos de implementación y revisión bajo dirección humana. Este documento no sustituye registro oficial ni asesoría jurídica.
