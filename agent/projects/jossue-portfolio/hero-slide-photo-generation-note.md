## Global Direction

Create premium, editorial, realistic photographs for the home hero carousel. The photos must support the current portfolio language: ecommerce product strategy, UX/CRO, Shopify development, and applied AI as an operable business system.

Use quiet, professional compositions with enough negative space for overlaid text and CTAs. Avoid fake UI text, fake logos, fictional brand marks, decorative gradients, cartoon style, and stock-photo exaggeration. If a human face is needed, use an attached real reference of Jossue Alcalá; if no reference is attached, do not invent his face. Prefer hands, workspace details, devices, product surfaces, and over-the-shoulder compositions.

## Recommended Sizes

- Master generation: 2880 x 1800 px, 16:10, landscape.
- Desktop export: 1920 x 1200 px, WebP or AVIF.
- Tablet export: 1600 x 1200 px, 4:3, WebP or AVIF.
- Mobile export: 1440 x 1920 px, 3:4, WebP or AVIF.
- Mobile safe crop: keep the main subject inside the center 70% width and center 62% height.
- Overlay safe area: reserve the left 58% of desktop and lower-middle 55% of mobile for title, subtitle, and CTAs.
- File naming: `hero-profile-desktop.webp`, `hero-profile-mobile.webp`, `hero-ux-desktop.webp`, `hero-ux-mobile.webp`, `hero-dev-desktop.webp`, `hero-dev-mobile.webp`.

## Quality Rules

- Generate at least two options per slide: one lighter editorial version and one slightly darker technical version.
- Favor real photography over illustration.
- Keep the subject away from exact text overlay zones.
- Use shallow depth of field only where it does not reduce usability of the hero.
- Avoid busy backgrounds, heavy shadows over overlay text areas, text embedded in the photo, mock logos, and images that look like generic stock.
- Final assets should compress below 350 KB per desktop image and below 280 KB per mobile image when possible.
