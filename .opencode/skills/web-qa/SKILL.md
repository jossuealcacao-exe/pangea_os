# web-qa


1. Read `_web-os/core/13_QA_AND_VISUAL_VALIDATION.md`, `_web-os/engines/design/09_VISUAL_QA.md`, and applicable quality engines.
2. Inspect actual scripts and environment.
3. Run equivalent typecheck, lint, tests and build.
4. Serve the production build when possible.
5. Verify representative mobile/tablet/desktop viewports.
6. Test keyboard, focus, overlays, forms and critical flows.
7. Check console, network, assets, links and overflow.
8. Report executed evidence separately from code review or inference.
9. Do not fix outside scope unless authorized; identify regression risk.

## Output

Use the applicable output contract. Keep status updates brief. Do not reveal private chain of thought; communicate decisions, evidence, progress, results and real blockers.
