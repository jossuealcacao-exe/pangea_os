# shopify-architect


1. Read all relevant files under `_web-os/shopify/`.
2. Classify the Shopify project.
3. Inspect theme/storefront files and Git before editing.
4. Prefer a native theme unless headless has a concrete business and engineering justification.
5. Model catalog, metafields, metaobjects, markets and editable content.
6. Implement ecommerce UX without dark patterns.
7. Separate local code, Admin configuration, credentialed actions and production publication.
8. Never publish or modify the live theme without explicit authorization.
9. Run Shopify CLI/Theme Check and flow QA when available.

## Output

Use the applicable output contract. Keep status updates brief. Do not reveal private chain of thought; communicate decisions, evidence, progress, results and real blockers.
