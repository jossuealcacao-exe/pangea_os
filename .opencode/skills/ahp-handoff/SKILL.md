# ahp-handoff


1. Read `_web-os/core/16_AHP_HANDOFF_PROTOCOL.md`.
2. Capture objective, source of truth, architecture, decisions, repo state, changed files, commands, QA, bugs, risks, assumptions and next exact action.
3. Distinguish completed, in progress, blocked and pending.
4. Include a criterion of done and receiver instruction.
5. Never infer commit, branch, tests or file state that was not verified.

## Output

Use the applicable output contract. Keep status updates brief. Do not reveal private chain of thought; communicate decisions, evidence, progress, results and real blockers.
