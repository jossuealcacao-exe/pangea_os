# Primer arranque en OpenCode

Dentro del proyecto:

```bash
opencode
```

Verifica:

```text
/os-status
```

Estrena el SO:

```text
/web-architect Modo BUILD. Inspecciona esta carpeta, normaliza el brief, selecciona arquitectura, activa solo los motores necesarios, implementa, ejecuta QA real y entrega AHP. No publiques, no hagas push y conserva cambios existentes. IDEA: [PEGA AQUÍ TU IDEA]
```

Para analizar antes de construir, cambia con `Tab` a `web-plan` o escribe:

```text
/web-architect Modo PLAN. [IDEA]
```
