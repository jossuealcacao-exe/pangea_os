# ChatGPT iOS workflow

1. Create a ChatGPT Project named `Pangea OS`.
2. Paste `PROJECT_INSTRUCTIONS.md` into project instructions.
3. Upload the eight files under `platforms/chatgpt/context-pack/`.
4. Connect GitHub when the app and account expose that connector.
5. Start with `/pangea status` and require repository evidence.
6. For edits, name repository, branch, project ID, scope and QA.
7. Ask for an AHP+ handoff before moving to Cursor, Claude Code, OpenCode or Codex.

Mobile access does not make all desktop coding capabilities available. Codex Remote, connectors and write actions depend on plan, app version and permissions. Git remains canonical.
