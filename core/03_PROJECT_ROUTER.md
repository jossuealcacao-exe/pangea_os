# Project router

## Resolution order

1. Project explicitly named in the command.
2. Project profile matching current working directory.
3. Single registered active project.
4. User confirmation.

## Isolation

Every profile has a stable `project_id`, path, stack, commands, design direction, source-of-truth files and known risks. A project-specific `AGENTS.md` may refine the root rules but cannot weaken safety, evidence or author authority.

## Shared learning

A pattern becomes shared knowledge only after:

- Evidence in at least one project.
- Removal of private or project-specific details.
- Review for general applicability.
- A decision record approving promotion.
