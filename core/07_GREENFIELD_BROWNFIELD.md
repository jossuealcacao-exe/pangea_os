# Greenfield and brownfield

## Greenfield

Define brief, constraints, architecture, design direction, data model, acceptance criteria and QA before implementation.

## Brownfield

Do not impose Pangea's preferred stack. First:

- Detect current framework and commands.
- Map architecture and conventions.
- Preserve behavior and working changes.
- Separate pre-existing failures.
- Create or update the project profile.
- Propose minimal, reversible changes.

Existing projects are the default case, not an exception.
