# AHP+ integration

Pangea uses AHP+ 1.0 as its state plane. `/agent` is not a folder of prose summaries; it is a typed, verifiable operational journal.

Every material session should leave:

- Updated current state.
- New records rather than silent rewrites.
- QA receipts.
- A handoff when work can continue elsewhere.

Use `node tools/ahp-plus/ahp.mjs verify .` before handoff.
