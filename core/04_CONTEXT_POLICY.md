# Context policy

## Load order

1. Kernel summary.
2. Current AHP+ state.
3. Active project profile.
4. Exact files involved.
5. Relevant engine.
6. Historical records only when they affect the decision.

## Never preload

- Every project source tree.
- Full chat exports.
- Archived sessions.
- All design styles.
- Unrelated bugs or backlogs.

## Context budget

Prefer indexes, profiles and record IDs. Open source files on demand. Summaries must link back to canonical records so another agent can verify them.
