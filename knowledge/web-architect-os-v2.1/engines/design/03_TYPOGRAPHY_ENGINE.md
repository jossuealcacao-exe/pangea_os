# Typography Engine

## Pareja tipográfica

- Display con carácter cuando el producto necesita identidad editorial.
- Sans o serif de lectura con alta legibilidad para cuerpo/UI.
- No usar más familias de las necesarias.

## MUST

- Escala fluida con `clamp()` cuando aporte.
- Cuerpo cercano a 1rem y line-height suficiente.
- Longitud de línea controlada.
- Pesos disponibles realmente cargados.
- Fallbacks compatibles.
- Fuentes locales o estrategia de carga responsable.

## Jerarquía

Patrón frecuente: kicker → título → bajada → contenido. No es obligatorio para dashboards o tareas densas.

## Anti-patrones

- Tracking negativo extremo en cuerpo.
- Contraste de tamaño sin contraste semántico.
- Texto diminuto para “verse premium”.
- Cargar múltiples pesos no usados.
