# Frontend Engineering

## Fundamentos

- HTML semántico.
- CSS moderno.
- TypeScript estricto cuando aplique.
- Componentes reutilizables.
- Datos separados de presentación.
- Tokens.
- Mobile-first.
- Progressive enhancement.
- Feature detection.

## TypeScript

- `strict`.
- Evitar `any`.
- Validar entradas externas.
- Considerar `noUncheckedIndexedAccess`.
- Considerar `exactOptionalPropertyTypes`.
- No silenciar errores globalmente.

## Assets

- SVG para vectores.
- AVIF/WebP para fotografía.
- PNG para transparencia.
- `srcset`, `sizes`, `width`, `height`.
- Lazy loading bajo el pliegue.
- Prioridad alta solo para LCP.
- Fallback.

## Estado

Local por defecto; URL para filtros compartibles; context para transversal moderado; store global solo con necesidad.

## Tecnología moderna

View Transitions, Server Components, Islands, streaming, edge o WebGL únicamente si mejoran el producto y tienen fallback o compatibilidad suficiente.
