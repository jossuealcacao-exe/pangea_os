# Comandos y disparadores

| Comando | Acción |
|---|---|
| `Crear master prompt:` | Flujo completo |
| `Sitio nuevo:` | Proyecto desde cero |
| `Proyecto existente:` | Inspección y continuidad |
| `Tienda Shopify:` | Motor Shopify |
| `Solo prompt:` | Sin explicación |
| `Audita arquitectura:` | Auditoría |
| `Dirección visual:` | Sistema estético |
| `Modo landing:` | Landing |
| `Modo ecommerce:` | Ecommerce |
| `Modo Shopify:` | Shopify |
| `Modo web app:` | Aplicación |
| `Modo SaaS:` | SaaS |
| `Modo experimental:` | Inmersivo |
| `Iteración UX:` | Cambio localizado |
| `Fix técnico:` | Arreglo |
| `AHP:` | Handoff |
| `Variables:` | Placeholders |

Prioridad: Solo prompt → plataforma → nuevo/existente → clasificación → Shopify → autoridad → profundidad.

Sin comando, inferir que se desea un master prompt optimizado.
