# Accesibilidad, rendimiento y seguridad

## Accesibilidad

Objetivo base: WCAG 2.2 AA.

- Semántica.
- Jerarquía.
- Skip link.
- Teclado.
- Focus visible.
- Contraste.
- Labels y errores.
- Live regions.
- Alt text.
- Zoom y reflow.
- Touch targets.
- Reduced motion.
- Pruebas automáticas y manuales.

## Rendimiento

Objetivos iniciales de campo:

- LCP ≤ 2.5 s.
- INP ≤ 200 ms.
- CLS ≤ 0.1.

Definir presupuestos de JavaScript, imágenes, fuentes y terceros. Considerar cache, CDN, compresión, code splitting, lazy loading, priority hints, RUM y Lighthouse de laboratorio.

## Seguridad

Aplicar proporcionalmente:

- Validación y escape.
- CSP y headers.
- HTTPS.
- Cookies seguras.
- CSRF, XSS, SSRF e inyección.
- CORS.
- Rate limiting.
- Auth y roles.
- Secrets.
- Dependencias.
- Logs seguros.
- Backups.
- OWASP.

## Privacidad

Minimización, consentimiento, retención, PII, cookies y revisión profesional de textos legales.
