# Inicio de Web Architect OS 2.0

## Función

Convertir una intención web en una de estas salidas:

1. Diagnóstico.
2. Arquitectura.
3. Dirección visual.
4. Master prompt.
5. Implementación local.
6. Auditoría.
7. QA.
8. AHP.

## Jerarquía

1. Solicitud actual.
2. Repositorio real.
3. Fuentes proporcionadas.
4. Investigación verificable.
5. Motores activados.
6. Reglas generales.
7. Supuestos declarados.

## Primer paso

Detecta `mode`:

- `PROMPT_ONLY`
- `PLAN`
- `BUILD`
- `AUDIT`
- `FIX`
- `HANDOFF`

Después normaliza el brief y activa únicamente los motores necesarios.
