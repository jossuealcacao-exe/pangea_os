# Changelog

## 2.1.0 — 2026-07-22

### Añadido

- Adaptador nativo para OpenCode.
- `AGENTS.md` y `opencode.json` de proyecto.
- Cinco skills bajo `.opencode/skills/`.
- Seis comandos TUI bajo `.opencode/commands/`.
- Agentes principales `web-build` y `web-plan`.
- Subagentes `visual-director`, `shopify-auditor` y `qa-auditor`.
- Guía completa de instalación para macOS.
- Instalador seguro para copiar el SO a un proyecto y respaldar colisiones.
- Plantilla global opcional para `~/.config/opencode/AGENTS.md`.
- OpenCode incorporado a la matriz de plataformas.

## 2.0.0 — 2026-07-22

- Arquitectura por motores intercambiables.
- Agent Skills.
- Visual Design Engine derivado del sistema Vineria.
- Drivers de estilos visuales.
- Adaptadores para Claude Code, Cursor, Codex y ChatGPT.
