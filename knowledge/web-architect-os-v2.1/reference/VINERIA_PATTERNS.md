# Patrones heredados de Vineria

## Principios

- Runtime autocontenido cuando aplica.
- Datos tipados como fuente única.
- Mobile-first.
- Accesibilidad y reduced motion desde el inicio.
- Tokens visuales.
- Investigación documentada.
- Copy humano.
- QA objetivo.
- Bugs convertidos en reglas.

## Patrones UX

- Tarjeta con un control enfocable.
- Grid stretch y CTA al fondo.
- IntersectionObserver con fallback.
- Scroll con altura acotada.
- Header con histéresis.
- Mapas con coordenadas reales.
- Documentación generada desde datos.

## Errores conocidos

Rutas de assets, índices TS, APIs ausentes en tests, scroll anchoring, grid sin altura, brillo neumórfico, rate limits, imágenes no verificadas, imports TS, banderas emoji, viewports headless y offsets decorativos.
