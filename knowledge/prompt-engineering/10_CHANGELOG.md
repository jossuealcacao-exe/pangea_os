# Changelog

## 1.0 — 2026-07-15

### Añadido

- Activación del SO de Ingeniería de Prompts.
- Instrucciones permanentes para proyectos de IA.
- Motor de clasificación de prompts.
- Modos de optimización, reconstrucción, auditoría, compacto, completo, agente, SO, visual, técnico, estratégico y AHP.
- Contratos de salida.
- Plantillas reutilizables.
- Checklist QA y puntuación PROMPT-10.
- Protocolo AHP para continuidad interplataformas.
- Adaptadores para ChatGPT Projects, Claude, Claude Code, Codex, Cursor, imagen, video y automatizaciones.
- Comandos rápidos y modificadores.
- Integración de la Guía Maestra como fuente normativa.

### Decisiones

- La intención del usuario tiene prioridad sobre la expansión creativa.
- La longitud del prompt debe ser proporcional al riesgo y complejidad.
- El sistema no debe preguntar por detalles menores.
- `Solo prompt` elimina cualquier explicación externa.
- El núcleo común será la fuente de verdad en salidas multiplataforma.

### Próxima versión sugerida

- Biblioteca de ejemplos por categoría.
- Esquema JSON opcional para prompts parametrizados.
- Sistema de versionado semántico de agentes.
- Matriz de pruebas comparativas entre modelos.
