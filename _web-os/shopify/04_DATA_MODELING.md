# Modelado Shopify

## Regla

Antes de crear metafields, comprobar si existe campo nativo.

## Productos

Definir product type, vendor, collections, tags operativas, variants, options, media, SEO, status, Markets e inventory.

## Metafields

Atributos simples ligados a recursos: material, medidas, cuidados, beneficios y especificaciones.

Definir namespace, key, type, validation, owner, traducción y uso.

## Metaobjects

Entidades reutilizables: artesanos, ingredientes, guías, FAQs, materiales, autores y contenido editorial.

## Regla

No usar HTML libre para información que necesita reutilización, filtros, traducción, validación o referencias.

## Migraciones

Documentar esquema, preparar datos de ejemplo, no borrar contenido y separar acciones locales de Admin.
