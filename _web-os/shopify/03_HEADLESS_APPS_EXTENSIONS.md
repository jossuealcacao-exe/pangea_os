# Headless, apps y extensiones

## Hydrogen

Considerar Storefront API, Customer Account API, Markets, cart, cache, SEO, streaming, hosting, variables, preview y observabilidad.

## Storefront API

Versionar consultas, usar tipos, manejar errores, contexto país/idioma, identidad de comprador, persistencia del carrito, límites y cache.

## Apps

Elegir app si requiere Admin API, OAuth, datos multi-store, UI administrativa o integración externa.

## Theme App Extensions

Usar app blocks y app embeds para insertar funcionalidad sin editar directamente el theme.

## Shopify Functions

Solo para capacidades soportadas de descuentos, delivery, payment customizations, validaciones o bundles.

## Seguridad

OAuth, scopes mínimos, HMAC, verificación de webhooks, idempotencia y secretos fuera del cliente.
