# Motor Shopify

## Activación

Se activa cuando el usuario menciona Shopify, existe un theme, se usa Shopify como backend o se solicita una app/extensión.

## Principio

Shopify debe respetar catálogo, variantes, inventario, Markets, checkout, Liquid, editor, metafields, metaobjects, apps y analytics.

## Arquitecturas

1. Theme nativo.
2. Customización de theme.
3. Theme custom.
4. Hydrogen headless.
5. Storefront API.
6. Theme App Extension.
7. App Shopify.
8. Shopify Functions.
9. Arquitectura híbrida.

## Preferencia

Theme nativo salvo que headless resuelva una necesidad concreta que compense coste, mantenimiento, APIs, cache, auth y hosting.

## Acciones humanas

Payments, cuentas bancarias, impuestos definitivos, tarifas reales, apps de pago, dominio, publicación, credenciales y políticas legales requieren acceso o aprobación humana.
