# Filosofía de diseño

## Fuente Vineria

- Editorial primero cuando el contenido lo pide.
- El contenido es fuente de verdad.
- Mobile-first real.
- Accesibilidad no negociable.
- Sin dependencias de adorno.
- El microcopy es diseño.

## Generalización

MUST:
- Subordinar estética a intención y contenido.
- Diseñar una tesis visual en una oración.
- Mantener jerarquía antes que decoración.
- Hacer que cada material, sombra y animación tenga función.

SHOULD:
- Reducir decisiones arbitrarias mediante tokens.
- Elegir componentes nativos antes que abstraer prematuramente.
- Diseñar estados vacíos, error, loading y disabled junto al estado ideal.

MUST NOT:
- Confundir premium con exceso de blur, sombras o motion.
- copiar literalmente una referencia sin reinterpretar la marca.
