# Visual Design Engine

## Tesis

La estructura y las reglas producen la calidad; la paleta produce la identidad.

## Proceso

1. Traducir intención emocional a atributos observables.
2. Elegir estilo dominante y secundario opcional.
3. Crear tokens semánticos.
4. Definir tipografía, retícula, superficies, estados y motion.
5. Diseñar primero móvil.
6. Construir componentes con estados completos.
7. Validar accesibilidad y anti-patrones.
8. Verificar visualmente en múltiples viewports.
