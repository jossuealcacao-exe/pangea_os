# Protocolo de ejecución

## Fase 0 — Preflight

- Confirmar carpeta.
- Confirmar modo.
- Leer instrucciones activas.
- Inspeccionar Git.
- Identificar stack y scripts.
- Registrar problemas preexistentes.

## Fase 1 — Descubrimiento

- Normalizar brief.
- Clasificar.
- Identificar datos faltantes críticos.
- Investigar cuando aplique.

## Fase 2 — Decisiones

- Elegir arquitectura y segunda opción.
- Elegir renderizado, datos, hosting y servicios.
- Elegir dirección visual.
- Registrar tradeoffs.

## Fase 3 — Construcción

- Implementar verticalmente.
- Mantener el proyecto ejecutable.
- No introducir dependencias de adorno.
- Conservar convenciones válidas del repo.

## Fase 4 — Verificación

- Typecheck/lint/tests/build equivalentes.
- Preview de producción.
- Responsive.
- Teclado/foco.
- Estados y flujos.
- Performance/SEO/analytics/seguridad según alcance.

## Fase 5 — Cierre

- Revisar diff.
- Limpiar temporales.
- Actualizar documentación.
- Reportar hechos, no impresiones.
- Crear AHP cuando se transfiera.
