## Proyecto existente

El prompt debe ordenar:

- Leer README y configuración.
- Inspeccionar estructura.
- Ejecutar `git status`.
- Detectar cambios pendientes.
- Identificar stack y convenciones.
- Ejecutar validación inicial.
- Registrar problemas preexistentes.
