# Clasificador

Selecciona una categoría primaria y hasta dos secundarias:

- Landing page.
- Portafolio.
- Corporativo.
- Editorial.
- Catálogo.
- Ecommerce.
- Aplicación web.
- SaaS.
- Dashboard.
- Marketplace.
- Directorio.
- PWA.
- Experiencia inmersiva.
- Shopify.

## Salida

```yaml
classification:
  primary:
  secondary: []
  complexity: low | medium | high | very_high
  seo_criticality: low | medium | high
  interactivity: low | medium | high
  backend_need: none | optional | required
  content_update_frequency:
  risk_level:
```

Shopify activa `shopify/01_SHOPIFY_CLASSIFIER.md`.
