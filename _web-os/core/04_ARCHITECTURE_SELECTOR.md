## Perfiles

- Landing/portafolio: Astro, HTML o React/Vite según interacción.
- Editorial/catálogo: Astro, Next, Nuxt o SvelteKit.
- App/SaaS: framework full-stack y monolito modular.
- Ecommerce: plataforma comercial, activar Shopify cuando aplique.
- Inmersivo: framework interactivo; Canvas/WebGL solo con justificación.
